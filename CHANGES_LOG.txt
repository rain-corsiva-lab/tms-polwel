ISSUE #1: EMAIL ATTACHMENT 404 ERROR
================================================================================

Problem:
  - POST /api/uploads/email-attachments returned 404 Not Found
  - Affected both learner confirmation and trainer assignment emails
  - Users unable to send email attachments

Root Cause:
  - Fetch calls using relative path: /api/uploads/email-attachments
  - Frontend on port 8080, backend on port 3001
  - Relative paths don't work across different ports

Solution:
  - Export API_BASE_URL from src/lib/api.ts
  - Update fetch calls to use full URL: ${API_BASE_URL}/uploads/email-attachments
  - Applied to both CourseRuns.tsx and SendTrainerEmailDialog.tsx

Files Modified:
  1. src/lib/api.ts
     - Added: export { API_BASE_URL };
